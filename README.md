## 🚀 Como Executar o Projeto

### Pré-requisitos
* [.NET SDK](https://dotnet.microsoft.com/download) instalado (versão 8.0 ou superior).
* Terminal (Bash, PowerShell, CMD ou terminal integrado do VS Code).
